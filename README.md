# 3D-Graphics-Engine
This is my first time creating and experimenting with 3D Graphics.
My goal with this project is not to create the greatest engine possible,
but to fully understand how 3D Graphics works (i.e. Perspective Projection and Rasterization).
The only library I am using is SDL (Simple DirectMedia Layer).

## My goal with this
My initial goal (as strange as it sounds) was to be able to render Mario from Super Mario 64 (and other low poly models from the N64 era). In the process I learned so much about 3D graphics and what else goes into it that it transformed into
just experimenting and implenting as many 3D graphics features that I could figure out how to do.
Some of these features include: Backface culling, the Painter's Algorithm, Normals, Lighting, and more!

I also implemented Frustum culling and a bitmap font renderer. These were some of the trickiest parts to figure out how to do on a software renderer.
